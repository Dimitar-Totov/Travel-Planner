## Commands

- `npm run dev` — start the dev server (http://localhost:3000)
- `npm run build` — production build

No test runner is set up yet.

## Architecture

Freshly scaffolded Next.js 16 App Router project — React 19, TypeScript, Tailwind CSS v4. Currently a single route.

- `src/app/layout.tsx` — root layout (Geist fonts via `next/font/google`); `src/app/page.tsx` — home page. New routes go under `src/app/**`.
- Path alias `@/*` maps to `src/*` (see `tsconfig.json`).
- Tailwind v4 has no `tailwind.config.js`: it's wired through the `@tailwindcss/postcss` plugin (`postcss.config.mjs`) and pulled in via `@import "tailwindcss"` plus an inline `@theme` block in `src/app/globals.css`.
- `types/routes.d.ts` and `types/validator.ts` are regenerated by Next's typed-routes feature on every `dev`/`build` — never hand-edit them. They're the source of the global `PageProps<Route>` / `LayoutProps<Route>` helper types; on any route, `params` and `searchParams` are `Promise`s and must be `await`ed.
- `next/cache` (see `types/cache-life.d.ts`) exports `updateTag`, `revalidateTag`, `revalidatePath`, `refresh`, `unstable_cache`, `unstable_noStore`, plus the `"use cache"` profile helpers `cacheLife`/`cacheTag`. Built-in `cacheLife` profiles: `default`, `seconds`, `minutes`, `hours`, `days`, `weeks`, `max`, or a custom `{ stale, revalidate, expire }` object.
